   git commit -m "feat: adicionados 18 novos slabs graduados e otimizacao webp"
4. Envie para o repositório remoto (se já tiver o remote configurado):
   git push origin main

Passo B - Publicação Gratuita na Web (Cloudflare Pages / Netlify):
- Cloudflare Pages (Recomendado):
  1. Acesse https://pages.cloudflare.com
  2. Clique em "Create a project" -> "Upload assets".
  3. Arraste a pasta `catalogodecartasgraduadas` inteira.
  4. Conecte seu domínio `catalogodecartasgraduadas.com.br` nas configurações.

- Netlify (Alternativa):
  1. Acesse https://app.netlify.com/drop
  2. Arraste a pasta do projeto.
  3. Configure o domínio personalizado.
